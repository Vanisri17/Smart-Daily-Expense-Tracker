# Smart Daily Expense Tracker

## About

Smart Daily Expense Tracker is a Python-based project used to record daily expenses, view saved transactions, and monitor a monthly budget.

## Features

* Add daily expenses
* Store expense records in a CSV file
* View all saved expenses
* Calculate total expenses
* Display remaining budget
* Warn when the budget is exceeded

## Technologies Used

* Python
* CSV module
* OS module
* Datetime module
* GitHub

## Project File

* `expense_tracker.py` – Main Python program
* `expenses.csv` – Expense data file created automatically when the program runs

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open `expense_tracker.py` in Python IDLE.
4. Run the program by pressing F5.
5. Select an option from the menu.

## Menu Options

1. Add Expense
2. View All Expenses
3. View Expense Summary
4. Exit
